Privacy Policy

Last updated: November 6, 2026

This policy describes how Dealer OS Backup ("the application") accesses and handles Google user data. The application is a personal backup tool used only by its owner to back up the owner's own server data to the owner's own Google Drive.

Google data the application accesses

The application requests a single OAuth scope:

  • https://www.googleapis.com/auth/drive.file — access only to files and folders that the application itself creates in Google Drive.

The application cannot see, read or modify any other files in the Google Drive. It does not access Gmail, contacts, calendar, profile data or any other Google service.

How the data is used

  • Google Drive access is used exclusively to upload, list, verify, download and delete the application's own backup files, i.e. for backup and restore.
  • All backup data is encrypted on the server by restic before it is sent to Google Drive. Only encrypted data is stored in Drive; the encryption password never leaves the server and is never sent to Google.
  • The data is not used for advertising, analytics, profiling, or training of AI/ML models, and is not sold.

Storage of OAuth tokens

OAuth access and refresh tokens are stored locally on the owner's server in the backup tool's configuration, with access restricted to the server owner. Tokens are not transmitted to any third party and are not stored in any external service.

Sharing

Google user data is not shared with, transferred to, or disclosed to any third party. The only parties involved are the owner's server and Google Drive itself.

Limited Use

The application's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Retention and deletion

Encrypted backups are kept in Google Drive according to the owner's retention settings and are removed when they are pruned or deleted. Access can be revoked at any time at myaccount.google.com/permissions; after revocation the application can no longer access Google Drive, and the locally stored tokens become invalid.

Changes

If this policy changes, the updated version will be published on this page with a new "Last updated" date.

Contact

Questions about this policy can be submitted via the project's GitHub repository.
