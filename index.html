Dealer OS Backup

Dealer OS Backup is a personal, single-owner backup system. It creates encrypted backups of the owner's own server data and stores them in the owner's own Google Drive.

How it works

  • Backups are made with restic, which encrypts all data on the server before it is uploaded.
  • rclone uploads the already-encrypted backup files to Google Drive using the Google Drive API.
  • The application requests only the drive.file scope, so it can access only the files and folders it created itself — not the rest of the Drive.
  • Google Drive access is used solely to store, list, verify and restore these backups.

Who it is for

This is not a public service. It is used only by its owner for their own data. There are no user accounts, no sign-up and no third-party users.

See the Privacy Policy for details on how Google user data is handled.
